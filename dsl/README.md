# mica_bff_dsl

A schema DSL for BFF block catalogues, and the generators that turn a catalogue into server code (Elixir) and client code (Swift). It knows no catalogue of its own: a project that uses it defines its blocks and tells the generators where they are.

- `lib/mica_bff_dsl/schema.ex`: the DSL (`defblock`, `field`)
- `lib/mica_bff_dsl/gen/`: the Elixir and Swift generators (`swift.swift.eex` is the Swift)
- `lib/mix/tasks/`: `mix bff.gen.elixir` and `mix bff.gen.swift`
- `docs/adr/`: [0001: spec format](docs/adr/0001-spec-format.md)

The generators (`MicaBffDsl.Gen.*`) depend only on the schema's public output: `__schema__/0` and the data it returns, as documented in `MicaBffDsl.Schema`. They never reach into the schema's internals (its macros, module attributes or validation), so the schema can change inside as long as that output stays the same. The Swift tests pass it as plain maps.

## Use

```elixir
# mix.exs
{:mica_bff_dsl, path: "../dsl"}

# .formatter.exs: write the DSL without parentheses
import_deps: [:mica_bff_dsl]

# lib/my_app/blocks.ex
defmodule MyApp.Blocks do
  use MicaBffDsl.Schema

  defblock :card do
    field :title, :string, required: true
    field :to, :string
  end
end

# config/config.exs (or pass --spec and --namespace)
config :mica_bff_dsl, spec: MyApp.Blocks, elixir_namespace: "MyApp.Blocks.Generated", swift_namespace: "Blocks"
```

```sh
mix bff.gen.elixir --out PATH   # one module per block: struct + to_map/1
mix bff.gen.swift --out PATH    # PATH/<swift_namespace>.swift: enum Block and a struct per block
```

Generated files start with a "Generated by mica-bff" header. A rerun replaces them, and never overwrites a hand-written file.

## Develop

```sh
mix test   # the Swift tests need swiftc; without it they are skipped locally, never in CI
```

The tests use their own catalogue, `test/support/catalogue.ex`.

## Moving to its own repo

Move `dsl/` out and change the dependency line of each project that uses it to a git or Hex dependency, e.g. `{:mica_bff_dsl, github: "…", tag: "v0.1.0"}`. Nothing else refers to the DSL by path ([ADR 0002](../docs/adr/0002-dsl-and-spec.md)).
